# SEO Repair Kit Roadmap

SEO Repair Kit is focused on practical technical SEO workflows for WordPress websites, with an emphasis on automation, maintainability, and scalable architecture.

---

# Current Stable Release

## v2.1.7

Production version currently available on WordPress.org.

### Included Areas

- Link Scanner
- Redirect Manager
- Schema Manager
- Meta Management
- Robots / LLMs controls
- KeyTrack workflows
- Dashboard and reporting tools
