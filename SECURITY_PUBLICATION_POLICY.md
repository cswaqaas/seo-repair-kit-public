# Security Publication Policy

The primary SEO Repair Kit development repository is not public by default.

## Why the main repository remains private

The private repository may contain:

- historical internal references
- company workflows
- experimental branches
- commercial implementation details
- historical debugging information
- release preparation notes
- old code that has not been audited for public exposure

## Public release strategy

Public-facing materials are published through this repository only after review.

Allowed public content:

- documentation
- roadmap
- architecture summaries
- screenshots without credentials
- WordPress.org release links
- safe changelogs
- sanitized examples

Not allowed:

- API keys
- credentials
- license secrets
- client-specific data
- private endpoints
- internal business logic
- unreviewed historical Git history
- private GitHub Actions logs

## Release evidence

WordPress.org remains the public distribution source for production plugin releases.

This repository acts as an OSS-facing transparency and documentation layer.
