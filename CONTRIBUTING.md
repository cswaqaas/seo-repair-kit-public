# Contributing

Thank you for your interest in SEO Repair Kit.

The main source repository is currently private, but public documentation improvements, roadmap suggestions, and issue reports are welcome here.

## How to Contribute

You may open issues for:

- documentation improvements
- feature suggestions
- WordPress SEO workflow ideas
- bug reports from the WordPress.org plugin
- security-safe improvement suggestions

## Guidelines

- keep issues clear and specific
- do not include private credentials
- do not share client data
- include WordPress/PHP version when reporting bugs
