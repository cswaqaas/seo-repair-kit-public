# Private Repository Policy

The main SEO Repair Kit source repository is maintained privately under the company organization.

## Reason

The repository includes long-term development history and company-owned implementation details.

Making the entire repository public could expose:

- historical internal references
- old experimental code
- private release workflow details
- commercial implementation logic
- unreviewed branch history
- internal GitHub Actions logs

## Public Alternative

Instead of making the private repository public, this repository provides a safe public layer containing:

- project overview
- architecture documentation
- release notes
- roadmap
- maintainer evidence
- WordPress.org references
- selected sanitized production snapshots
- release-readiness audit notes

## Contribution Proof

Private commits may still appear in the maintainer's GitHub contribution graph if private contribution visibility is enabled.

Public proof is supported through:

- WordPress.org plugin profile
- public documentation
- screenshots
- release notes
- linked maintainer profiles
- sanitized v2.1.7, v2.1.9, and v2.1.10 code snapshots
- v2.1.8, v2.1.9, and v2.1.10 release trail documentation
- v2.1.9 compatibility audit
