SEO Repair Kit is a WordPress SEO plugin focused on technical SEO automation, schema management, link auditing, redirect workflows, and scalable optimization systems.

The production plugin is available on WordPress.org:

https://wordpress.org/plugins/seo-repair-kit/

## Project Focus

SEO Repair Kit is designed for:

- WordPress site owners
- SEO teams
- agencies
- developers maintaining technical SEO workflows

## Core Areas

- Technical SEO automation
- Link scanning and audit workflows
- Schema management
- Meta management
- Redirect management
- Spam Monitor workflows
- WordPress admin tooling
